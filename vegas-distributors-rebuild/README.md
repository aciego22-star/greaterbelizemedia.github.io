# Vega's Distributors — concept website rebuild

A concept rebuild of the Vega's Distributors Ltd. website, built from information
the company published publicly and captured on 8 September 2026.

**This is not an approved site.** Nothing here has been confirmed as current by
the business. Do not deploy it to a live domain, and do not replace the existing
vegasdistributors.bz website, without explicit authorisation.

## Stack

Plain static HTML, CSS and JavaScript, generated by a small Node build script.
The repository it lives in is a hand-written static site with no framework or
bundler, so this project follows the same approach rather than introducing one.

There is no client-side router: every route is a real directory with its own
`index.html`, so direct visits and refreshes work without redirect rules, and
every page is crawlable without running JavaScript. All asset and link
references are relative, so the output runs from a domain root, a subdirectory,
or straight off the filesystem.

Runtime dependencies: none. `sharp` is used at build time only, to produce
optimised images, and is not needed to build the site from committed sources.

## Commands

```bash
npm install          # sharp, for the image pipeline only
npm run build        # generate dist/
npm run check        # QA the built output (links, metadata, headings, images)
npm run serve        # serve dist/ at http://localhost:4321
npm run dev          # build, then serve
npm run package      # build + check + write the Netlify upload ZIP
```

`npm run build` works from a clean clone. The two scripts below need the original
handoff pack and only have to be re-run if the source material changes:

```bash
npm run extract -- --pack /path/to/vegas_cc_pack   # rebuild data/catalog.json
npm run images  -- --pack /path/to/vegas_cc_pack   # rebuild src/assets/images
npm run fonts                                       # re-download the bundled fonts
```

## Layout

```
data/            content model
  company.json     verified company facts, divisions, contacts, territories
  catalog.json     37 brands, 346 product listings, generated from the pack
  images.json      image manifest with intrinsic dimensions
  site.json        build flags and integration points
i18n/            en.json / es.json — all interface copy
scripts/         build, extraction, image, QA and packaging scripts
  lib/             layout, partials and page templates
src/             stylesheets, client JavaScript, fonts, optimised images
dist/            build output (committed, so the deliverable travels with the repo)
release/         Netlify upload ZIP (git-ignored; regenerate with npm run package)
```

## Content rules this build follows

- Every product name and pack size is reproduced exactly as published. Nothing
  is invented, corrected or translated.
- No price, stock level, delivery promise, rating or SKU appears anywhere,
  because no approved source for any of them exists.
- Categories the company lists among its imports but does not detail online
  (hotel supplies, construction, wines and spirits, lubricants) are shown in an
  explicit enquiry-only state rather than filled with guesses.
- Telephone and email actions are rendered only where a number or address is
  actually published. The Stann Creek territory shows a note instead of a
  fabricated number, and no WhatsApp link exists because none is published.
- The generic `stafficon` and `womanicon` images in the pack are not used. Space
  for authentic facility, fleet and staff photography is marked as pending.
- Product listings are labelled provisional wherever they appear.

## Integration points

| What | Where | Status |
| --- | --- | --- |
| Enquiry backend | `data/site.json` → `forms.endpoint`; posted by `src/js/enquiry.js` | Not connected. The form validates and shows the exact payload a backend would receive. It never reports success. |
| Analytics | `scripts/lib/layout.mjs`, marked in `page()` before the site script | Not loaded. Add a deferred tag at the marker. |
| AI Employee | `data/site.json` → `assistant.enabled` | Disabled. Nothing is advertised or contacted while false. No vendor is named. |
| Indexing | `data/site.json` → `noindex` | `true`. Drives both the robots meta tag and `robots.txt`. Set to `false` only when a production launch is approved. |
| Canonical host | `data/site.json` → `siteUrl` | `https://www.vegasdistributors.bz`, for an eventual approved migration. |

## Deploying

`npm run package` writes `release/Vegas Distributors Netlify Upload.zip`,
containing `index.html` at its root plus every asset, and nothing else. Upload
it to Netlify manually. `dist/netlify.toml` and `dist/_headers` set caching and
security headers; no redirect rules are needed.

Before any production launch, set `noindex` to `false` in `data/site.json` and
rebuild, otherwise the site ships with indexing disabled.
